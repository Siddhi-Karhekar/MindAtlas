# Sample notes

Two small sets of notes, written for this project, so that
`npm run eval:generate -- evaluation/samples` works on a fresh checkout and
the tests have something fixed to run on.

- `dbms_unit4.md` - clean notes with headings, lists and a table.
- `distributed_systems_unit1.txt` - deliberately messy: a college header,
  notices to the class, exercises and a reference line mixed in with the
  subject. `distributed_systems_unit1.txt.offtopic.txt` labels those lines.

**Do not report results from these files.** The generator's rules were written
while looking at them, so it does better here than it will on notes it has
never seen. Use real notes for anything that goes into a report; see
`docs/EVALUATION.md`.
